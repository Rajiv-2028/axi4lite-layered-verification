# AXI-4-Lite Protocol Verification using Layered testbench

A 16-register AXI4-Lite slave (`rtl/axi_slave_v2.sv`) and a layered SystemVerilog testbench to verify it.

Work in progress: the testbench, coverage, synthesis results and full documentation are added in the next updates.

- `rtl/` : the design
- `docs/AXI4LITE_BASICS.md` : what AXI4-Lite is
- `docs/DESIGN.md` : how the design works, line by line
